# 简历面试手册 · Resume Interview Playbook

一个 [WorkBuddy](https://www.workbuddy.cn) Skill：把**简历 + 岗位 JD** 变成一份可以直接拿去备考的面试手册，面试结束后再把**逐字稿或反馈**变成复盘报告。产出是单文件、可离线打开的 HTML。

> 核心原则：只用简历里能证明的事实，不编造数据。缺的信息会被标成「待补」，留给你在面试前填上真实内容。

---

## 两种模式

| 模式 | 什么时候用 | 你需要提供 | 产出 |
|---|---|---|---|
| **面前手册 Prep** | 拿到面试通知，准备一面 / 二面 / 主管面 / HR 面 | 简历（PDF 或文本）+ JD（文本或截图），可选：上一轮反馈 | `面试手册.html` |
| **面后复盘 Review** | 面完一轮，想知道哪里失分、下一轮怎么准备 | 面试逐字稿 / 回忆的问题清单 / 面试官反馈 + 简历 | `面试复盘.html` |

两种模式可以串起来用：复盘得出的「修复规则」会自动带进下一轮手册的「上一轮复盘」章节。

## 产出内容

**面前手册**
1. 定位一句话 —— 面试官会记住你的一句话，以及支撑它的三条证据
2. JD 匹配矩阵 —— 岗位职责 → 简历证据 → 岗位翻译 → 缺口与诚实补位说法
3. 上一轮复盘（有反馈时）
4. 业务与平台理解 —— 用户、闭环、岗位杠杆点
5. 简历追问防守地图 —— 每个数字、奖项、“主导/全流程”表述的追问链和归因边界
6. 面试流程与时间分配
7. 60–90 秒自我介绍（按节拍分段）
8. 至少 8 道定制高频问答（考察意图 / 回答骨架 / 参考回答 / 避坑）
9. 场景案例题（目标 → 用户分层 → 机制 → 指标与复盘）
10. 反问清单
11. 面前检查清单

**面后复盘**
1. 面试还原 —— 逐题标注「稳 / 弱 / 失分」
2. 失分点诊断 —— 归入 6 类：结构缺失、证据不足、归因不清、业务理解浅、能力缺口、动机模糊
3. 修复规则 —— 每个失分点一条可执行规则
4. 关键回答重写
5. 下一轮追问预测
6. 补课清单

## 设计

- **固定模板**：杂志风排版，米白纸感底色 + 祖母绿主色，左侧目录导航，支持打印。
- **证据标签**：`简历可证` / `岗位翻译` / `缺口风险` / `推断` 四色标注，哪句话有出处一眼可见。
- **完全离线**：不依赖外部字体、脚本和图片，发给别人也能直接打开。

## 安装

**方式一：在 WorkBuddy 的 Skill 平台安装**（推荐）

**方式二：手动安装**

```bash
git clone https://github.com/AuyeungZEKI/resume-interview-html-playbook.git \
  ~/.workbuddy/skills/resume-interview-html-playbook
```

重启 WorkBuddy 后即可使用。

## 使用示例

直接在对话里说，附上文件即可：

- 「这是我的简历和 JD 截图，帮我准备下周的产品经理二面」
- 「根据简历和这个 JD 出一份面试手册」
- 「这是刚才面试的逐字稿，帮我复盘，看看下一轮怎么准备」
- 「面试官说我回答缺少数据支撑，帮我改一下这几题」

文件默认保存在当前工作区的 `interview_prep/` 下：

```
interview_prep/
├── inputs/<公司>_<岗位>/            # 简历、JD、逐字稿的副本（原文件不会被改动）
└── outputs/<公司>_<岗位>_<日期>/     # 面试手册.html / 面试复盘.html
```

## 目录结构

```
resume-interview-html-playbook/
├── SKILL.md                    # 触发条件与工作流程
├── assets/template.html        # 固定 HTML 模板（两种模式共用）
└── references/
    ├── answer-rules.md         # 证据规范、回答结构、各轮侧重、避坑清单
    └── review-mode.md          # 面后复盘流程与失分分类
```

## 注意

- 生成的回答是**备考参考**，请改成自己的话说出来，并把所有「待补」项换成你本人的真实数据。
- 涉及公司内部项目的经历会做脱敏处理，但上传简历前也请自行确认不含敏感信息。
